Kurulum Kılavuzu

Cihazları SysTrack'e nasıl hazırlarsınız?

SysTrack, Windows cihazlardan donanım, yazılım ve lisans bilgilerini WinRM protokolü üzerinden toplar. Taranacak her Windows cihazda aşağıdaki tek seferlik kurulumun yapılması yeterlidir.

Gereksinimler
WinRM servisi çalışıyor ve otomatik başlatma açık
Port 5985 güvenlik duvarında açık (gelen bağlantılar)
Yerel yönetici hesabı — kullanıcı adı ve parola
Ağ profili Özel veya Etki Alanı olmalı (Public/Ortak değil)
Admin PowerShell 
# Ağ profilini Private'a çevir
Get-NetConnectionProfile | Where-Object NetworkCategory -eq 'Public' | Set-NetConnectionProfile -NetworkCategory Private

# WinRM'i etkinleştir ve yapılandır
winrm quickconfig -force
winrm set winrm/config/service "@{AllowUnencrypted=`"true`"}"
winrm set winrm/config/service/auth "@{Basic=`"true`"}"
Set-Item WSMan:\localhost\Client\TrustedHosts -Value '*' -Force

# Güvenlik duvarı kuralı ekle
New-NetFirewallRule -DisplayName 'SysTrack-WinRM' -Direction Inbound -Protocol TCP -LocalPort 5985 -Action Allow -Profile Any -ErrorAction SilentlyContinue

Restart-Service WinRM -Force
Write-Host 'Hazır! SysTrack artık bu cihazı tarayabilir.' -ForegroundColor Green

Nasıl uygulanır?

1

Hedef Windows cihazda Başlat → PowerShell yazın → Sağ tık → Yönetici olarak çalıştır

2

Yukarıdaki Kopyala butonuna basın, PowerShell'e yapıştırın (sağ tık) ve Enter'a basın

3

"Hazır! SysTrack artık bu cihazı tarayabilir." mesajını gördüğünüzde kurulum tamamdır

4

SysTrack panelinde Keşif Ayarları → Domain Dışı Windows Cihazlar bölümüne cihazı ekleyin

Domain makineler için bu scripte gerek yok. Domain yöneticisi GPO ile WinRM'i tüm makinelerde merkezi açabilir. Keşif Ayarları → LDAP/AD bilgilerini girmeniz yeterlidir.

Linux cihazlarda SysTrack SSH üzerinden sistem bilgilerini toplar. Çoğu Linux sunucusunda SSH zaten aktiftir — genellikle ek kurulum gerekmez.

Gereksinimler
OpenSSH Server kurulu ve çalışıyor
Port 22 güvenlik duvarında açık
Kullanıcı adı + parola veya SSH anahtar doğrulaması
Terminal 
# SSH servis durumunu kontrol et
systemctl status ssh || systemctl status sshd

# Kurulu değilse kur (Ubuntu/Debian)
sudo apt-get install -y openssh-server

# Kurulu değilse kur (RHEL/CentOS/Rocky)
sudo yum install -y openssh-server

# Servisi başlat ve otomatik başlatmaya al
sudo systemctl enable --now ssh

# Güvenlik duvarı (ufw varsa)
sudo ufw allow 22/tcp

Keşif Ayarları → SSH Ayarları bölümüne cihazın IP adresini ve kullanıcı bilgilerini girin. root veya sudo yetkili hesap kullanmanızı öneririz.

Hedef ile Bağlantı Kurun

Cihazın çevrimiçi durumu ve yanıt süreleri için Hedefler sayfasında hedef oluşturup envanter kaydıyla bağlayın.

Envanter varlığın kimlik kartıdır; Hedefler ise canlı izleme merkezidir. İkisini birlikte kullanın.

Keşif Ayarları

Active Directory, WinRM ve SNMP ayarlarını yapılandırın

Keşif Metodları

LDAP / Active Directory OPSİYONEL

Windows PC'leri AD'den çeker + WinRM ile donanım bilgisi toplar

Bağlantı Ayarları

Kimlik Bilgileri

OU=Resepsiyon,DC=... → Lokasyon: "Resepsiyon"

WinRM (Otomatik)

Windows cihazlardan LDAP kimlik bilgileriniz ile otomatik olarak donanım bilgisi (CPU, RAM, Disk, Marka/Model) toplanır.

Ek ayar gerekmez - yukarıdaki AD kullanıcı adı ve parolası kullanılır.

Domain Dışı Windows Cihazlar OPSİYONEL

Active Directory'de olmayan Windows PC'leri IP + kimlik bilgisiyle keşfe dahil eder

Keşif başlatıldığında etkin cihazlar otomatik olarak taranır

SNMP OPSİYONEL

Network cihazlar için bilgi toplar (switch, router, printer)

Network cihazlar (yazıcı, tarayıcı, switch, router) için SNMP seçiliyse bu IP aralıkları taranır (CIDR, aralık veya tekli IP).

SSH OPSİYONEL

Linux/macOS cihazlardan sistem bilgisi toplar (CPU, RAM, Disk, Network)

Linux/Unix cihazlar için SSH seçiliyse bu IP aralıkları taranır (CIDR, aralık veya tekli IP).

Lisans Uyumluluk Taraması WinRM gerekli

Keşif sırasında Windows cihazlarında crack araçları, aktivasyon durumu ve imza geçerliliğini kontrol eder

Örn: DC=otel,DC=local - Boş bırakılırsa rootDSE'den otomatik alınır

Her satıra bir OU Distinguished Name yazın
