SNMP Kılavuzu

Server Durumu için SNMP nasıl açılır?

Aşağıdan işletim sisteminizi seçin ve adımları takip edin. Community string ve SNMP versiyonu SysTrack hedefiyle aynı olmalıdır.

Windows 10/11

  1. SNMP özelliğini yükleyin: 
    Add-WindowsCapability -Online -Name "SNMP.Client~~~~0.0.1.0"
Set-Service -Name SNMP -StartupType Automatic
Start-Service -Name SNMP

    PowerShell'i yönetici olarak çalıştırın.

  2. Community string ve erişim kısıtlarını ayarlayın:

    services.msc > SNMP Service > Security sekmesinde Accepted community names listesine SysTrack'te kullanacağınız string'i ekleyin ve Accept SNMP packets from kısmında SysTrack cihazının IP'sine izin verin.

  3. Windows Firewall'da UDP 161'i açın: 
    New-NetFirewallRule -DisplayName "SNMP" -Direction Inbound -Protocol UDP -LocalPort 161 -Action Allow
  4. Bağlantıyı test edin:

    SysTrack ile aynı string'i kullanarak snmpwalk -v2c -c <community> localhost 1.3.6.1.2.1.1.1 komutundan cevap aldığınızdan emin olun.

Ubuntu / Debian tabanlı Linux

  1. SNMP daemon'ını yükleyin: 
    sudo apt update && sudo apt install snmp snmpd
  2. Konfigürasyonu düzenleyin:

    /etc/snmp/snmpd.conf dosyasında aşağıdaki satırların olduğundan emin olun:

    agentAddress udp:161
rocommunity <community> <systrack_ip>/32
sysLocation "Server Room"
sysContact admin@example.com

    Daha geniş erişim gerekiyorsa CIDR bloğunu güncelleyebilirsiniz.

  3. Servisi yeniden başlatın ve açılışta aktif edin: 
    sudo systemctl enable --now snmpd
  4. Firewall'da UDP 161 portunu açın: 
    sudo ufw allow 161/udp
  5. snmpwalk ile test edin:

    snmpwalk -v2c -c <community> localhost 1.3.6.1.2.1.1.1

macOS (Homebrew + Net-SNMP)

  1. Net-SNMP paketini yükleyin: 
    brew install net-snmp
  2. Konfigürasyonu hazırlayın: 
    sudo cp /opt/homebrew/etc/snmp/snmpd.conf.example /opt/homebrew/etc/snmp/snmpd.conf
sudo nano /opt/homebrew/etc/snmp/snmpd.conf

    Dosyaya agentAddress udp:161 ve rocommunity <community> default satırlarını ekleyin.

  3. Servisi başlatın: 
    brew services start net-snmp

    macOS yeniden başlatıldığında servis otomatik olarak ayağa kalkar.

  4. Firewall'da UDP 161'e izin verin:

    System Settings > Network > Firewall menüsünden net-snmp'e izin verin veya `sudo /usr/libexec/ApplicationFirewall/socketfilterfw --add /opt/homebrew/sbin/snmpd` komutunu kullanın.

  5. snmpwalk ile doğrulayın:

    snmpwalk -v2c -c <community> localhost 1.3.6.1.2.1.1.1

İpucu

SNMP sorguları UDP üzerinden olduğu için hedef cihaz ile SysTrack arasında yönlendirici, VLAN veya güvenlik duvarı varsa UDP/161 trafiğini geçirdiğinden emin olun. Community string küçük/büyük harf duyarlıdır.
