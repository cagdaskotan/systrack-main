IP-Konfiguration für die eth0-Schnittstelle des Geräts

IP-Konfiguration

Wählen Sie die passende Subnetzmaske für Ihr Netzwerk.

Wenn leer, funktioniert der automatische DHCP-Wechsel beim Umzug in ein anderes Netzwerk nicht.

Wenn leer, wird 8.8.8.8 als Standard verwendet

Wenn leer, wird 1.1.1.1 als Standard verwendet

Nach einer IP-Änderung kann die Verbindung unterbrochen werden. Verbinden Sie sich ggf. mit der neuen IP erneut.

IP-Zulassungsliste

Wenn aktiviert, dürfen nur freigegebene IP-Adressen zugreifen.

Regelstatus
Zugriffsbeschränkung
Wenn die Zulassungsliste aktiv ist, werden alle nicht gelisteten IP-Adressen blockiert.
Bei aktiver Zulassungsliste funktionieren systrack:8080 und systrack.local:8080 eventuell nicht; verwenden Sie IP:8080.
Für den Zugriff per Telefon wird eine statische VPN-IP empfohlen.

Zugelassene IPs

Nur gelistete IPs können zugreifen.
