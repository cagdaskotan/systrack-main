Modulberechtigungen

Verwalten Sie als Administrator die Zugriffs- und Bearbeitungsrechte der Benutzer für SysTrack-Module. Wählen Sie einen Benutzer und aktualisieren Sie seine Anzeige- und Bearbeitungsrechte.

Nur Administratoren können auf diese Seite zugreifen.

Administrator-Benutzer

Administratoren haben vollen Zugriff auf alle Module und ihre Berechtigungen können nicht geändert werden.

Wählen Sie einen Benutzer aus, um die Berechtigungen zu bearbeiten.
