SNMP Guide

How to enable SNMP for Server Status?

Select your operating system below and follow the steps. The community string and SNMP version must match the SysTrack target.

Windows 10/11

  1. Install the SNMP feature: 
    Add-WindowsCapability -Online -Name "SNMP.Client~~~~0.0.1.0"
Set-Service -Name SNMP -StartupType Automatic
Start-Service -Name SNMP

    Run PowerShell as Administrator.

  2. Configure the community string and access restrictions:

    In services.msc > SNMP Service > Security, add the string you will use in SysTrack to Accepted community names and allow the SysTrack IP under Accept SNMP packets from.

  3. Allow UDP 161 in Windows Firewall: 
    New-NetFirewallRule -DisplayName "SNMP" -Direction Inbound -Protocol UDP -LocalPort 161 -Action Allow
  4. Test the connection:

    Make sure you get a response from snmpwalk -v2c -c <community> localhost 1.3.6.1.2.1.1.1 using the same string as SysTrack.

Ubuntu / Debian based Linux

  1. Install the SNMP daemon: 
    sudo apt update && sudo apt install snmp snmpd
  2. Edit the configuration:

    Make sure the following lines exist in /etc/snmp/snmpd.conf:

    agentAddress udp:161
rocommunity <community> <systrack_ip>/32
sysLocation "Server Room"
sysContact admin@example.com

    Adjust the CIDR block if broader access is needed.

  3. Restart the service and enable it on boot: 
    sudo systemctl enable --now snmpd
  4. Open UDP 161 on the firewall: 
    sudo ufw allow 161/udp
  5. Test with snmpwalk:

    snmpwalk -v2c -c <community> localhost 1.3.6.1.2.1.1.1

macOS (Homebrew + Net-SNMP)

  1. Install the Net-SNMP package: 
    brew install net-snmp
  2. Prepare the configuration: 
    sudo cp /opt/homebrew/etc/snmp/snmpd.conf.example /opt/homebrew/etc/snmp/snmpd.conf
sudo nano /opt/homebrew/etc/snmp/snmpd.conf

    Add agentAddress udp:161 and rocommunity <community> default to the file.

  3. Start the service: 
    brew services start net-snmp

    The service starts automatically after macOS restarts.

  4. Allow UDP 161 in the firewall:

    Allow net-snmp in System Settings > Network > Firewall or use `sudo /usr/libexec/ApplicationFirewall/socketfilterfw --add /opt/homebrew/sbin/snmpd`.

  5. Validate with snmpwalk:

    snmpwalk -v2c -c <community> localhost 1.3.6.1.2.1.1.1

Tip

SNMP queries use UDP. If there is a router, VLAN, or firewall between the target device and SysTrack, make sure UDP/161 traffic is allowed. Community strings are case-sensitive.
