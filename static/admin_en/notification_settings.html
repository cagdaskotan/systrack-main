How to get your Telegram Chat ID and set up notifications

To receive notifications via Telegram you need two things: start our bot and find your own Chat ID.

1

In Telegram, open the SysTrack Bildirim Botu (@systrack_alerts_bot) and press Start. This is required so the bot can message you.

2

To find your Chat ID, open the User Info bot (@userinfobot) and press Start. The bot replies with a number starting with Id: — that is your Chat ID.

3

When creating a notification, choose Channel = Telegram and enter this Chat ID in the Recipients field. Then verify with Send Test.

Example — User Info bot screen

If you don't press Start on the bot (@systrack_alerts_bot), Telegram won't allow messages even with the correct Chat ID.

A notification rule checks the selected targets/sensors at set intervals and sends an alert via the chosen channel (email or Telegram) when the condition is met.

Notification Types and Their Inputs

Target Monitoring

Triggers when the target(s) go online/offline or the response time crosses your threshold. Target selection + (optional) status/response-time condition.

Air Sensor

Alerts when temperature, humidity, pressure or air quality (IAQ) crosses a threshold. Sensor serial + field + operator + threshold.

Liquid Sensor

Alerts when the liquid level/state condition is met.

Camera

Sends alerts on camera-related events.

Crack Detection

Alerts when unlicensed/cracked software is detected on a device.

Common Fields for Every Notification
Name — a short name for the rule.
Channel — Email or Telegram.
Recipients — email address(es) or Telegram Chat ID. Verify with Send Test.
Frequency — check interval (e.g. 10 min). With Smart (decreasing): an immediate alert when the device goes offline, then increasingly sparse reminders (hourly → every 2 hours → daily) and the total downtime when it recovers — prevents notification floods during long outages.
Template (optional) — customizes the message; default text is used otherwise.

A single rule allows up to 50 targets. Create multiple rules for more targets.

How does the smart (decreasing) interval work?
As soon as the device goes offline, an immediate alert is sent.
First 3 hours: hourly reminders.
3–24 hours: every 2 hours.
After 24 hours: daily.
When it comes back online, an immediate alert with the total downtime.
Prevents notification floods during long outages. Only for Target Monitoring + Status condition.
Notification is sent when the target goes offline/online.
